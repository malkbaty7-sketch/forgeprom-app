# Forgeprom Code Studio

**استوديو عربي لصياغة الموجزات (البرومبتات) الهندسية الاحترافية** — حوّل فكرتك العربية الحرة إلى موجه هندسي كامل جاهز للنسخ في منصات بناء الكود (Claude، ChatGPT، Cursor، Replit…).

تطبيق **Android أصلي** (Kotlin + Jetpack Compose + Material 3)، يعمل **محلياً دون إنترنت** بمحرك قاعدي عربي، مع محركات سحابية **اختيارية بموافقة صريحة**.

## الميزات (سجل صادق)

| الميزة | الحالة |
|---|---|
| واجهة عربية RTL + وضع فاتح/داكن | ✅ جاهز |
| تحليل الفكرة العربية (نية، ميزات، متطلبات، افتراضات معلنة، أسئلة ≤3) | ✅ جاهز — محلي دون إنترنت |
| توليد برومبت 12 قسماً (عربي / إنجليزي / ثنائي) | ✅ جاهز |
| فحص جودة 14 عنصراً + إصلاح تلقائي | ✅ جاهز |
| النقد والاقتراح (نقاط قوة/نواقص/مخاطر) | ✅ جاهز |
| إدارة المشاريع (إنشاء/تثبيت/أرشفة/حذف) + محرر موجزات | ✅ جاهز |
| تصدير TXT / MD / JSON + نسخ ومشاركة (UTF-8) | ✅ جاهز |
| تحليل صور الواجهات (Gemini Vision) | ✅ سحابي اختياري بموافقة — غير متاح محلياً بصدق |
| محرك محلي قاعدي دون إنترنت | ✅ جاهز |
| نموذج عصبي محلي على الجهاز | ⏳ قيد التكامل لاحقاً |
| تشغيل الكود داخل المحرر | ⏳ مؤجل بدواعٍ أمنية |

**مبدأ الصدق:** لا تُعلن ميزة جاهزة قبل عملها فعلياً. الموافقة على السحابة **مرفوضة افتراضياً** — لا يغادر أي محتوى جهازك دون موافقتك الصريحة.

## البدء السريع

```bash
git clone https://github.com/malkbaty7-sketch/forgeprom-app.git
cd forgeprom-app
gradle assembleDebug     # أو افتح المشروع في Android Studio (JDK 17)
```

- متطلبات البناء: JDK 17، Gradle 8.9، AGP 8.5.2، Kotlin 2.0.20، compileSdk 35، minSdk 26.
- الخرج: `app/build/outputs/apk/debug/app-debug.apk`.
- الاختبارات: `gradle testDebugUnitTest` (8 اختبارات لطبقة المجال).

## البناء التلقائي (CI)

يرفع كل دفعة إلى `main` إلى سير عمل GitHub Actions (`.github/workflows/android.yml`):
1. `testDebugUnitTest` — اختبارات طبقة المجال.
2. `assembleDebug` — بناء APK.
3. رفع الناتج كـ artifact باسم **forgeprom-debug-apk** — نزّله من تبويب Actions.

## البنية

- `domain/` — محلل الأفكار، مولد البرومبت، فحص الجودة، النقد (Kotlin نقي قابل للاختبار).
- `core/` — المحركات (محلي قاعدي + Gemini + متوافق OpenAI)، Room، الإعدادات، مفاتيح مشفّرة، التصدير.
- `ui/` — Compose: شاشات الرئيسية/التوليد/التحليل/النتيجة/الصور/المشاريع/المحرر/المحركات/الإعدادات.
- `docs/` — الخطة، PRD، المعمارية، سجل التغييرات.

## الخصوصية

- كل شيء يعمل محلياً افتراضياً (المحرك القاعدي لا يحتاج إنترنت).
- مفاتيح API تُحفظ مشفّرة (EncryptedSharedPreferences).
- أي استدعاء سحابي (Gemini / OpenAI) محجوب خلف بوابة موافقة صريحة.
