# سجل التغييرات

## v1.0.0-mvp — versionCode 2 (2026-11-09)

النسخة الأولى القابلة للاستخدام.

### أُضيف

- تحليل الفكرة العربية محلياً: نية (11 نوعاً)، ميزات، متطلبات، قيود، افتراضات معلنة، أسئلة ≤3.
- مولد برومبتات 12 قسماً بثلاث لغات (عربي/إنجليزي/ثنائي) مع قيود منع التضخم.
- فحص جودة 14 عنصراً (خصم 7 لكل ناقص) + إصلاح تلقائي عند <70.
- النقد والاقتراح: نقاط قوة/نواقص/مخاطر/اقتراحات.
- إدارة مشاريع Room كاملة (إنشاء/تثبيت/أرشفة/حذف) + سجل نشاطات.
- محرر موجزات بعدادات كلمات/أحرف وحفظ ونسخ وتصدير.
- تصدير TXT/MD/JSON عبر FileProvider + مشاركة + نسخ حافظة (UTF-8).
- محرك محلي قاعدي يعمل دون إنترنت (ويرث فلسفة محرك v9.1).
- محركات سحابية اختيارية: Gemini 2.0 Flash (+Vision للصور) ومتوافق OpenAI — خلف بوابة موافقة صريحة.
- تحليل صور الواجهات: إقرار «استلهام فقط» + حد 5MB + ثقة وافتراضات معلنة.
- مفاتيح API مشفّرة (EncryptedSharedPreferences).
- سجل ميزات صادق (FeatureRegistry) وحول التطبيق.
- 8 اختبارات وحدة لطبقة المجال + سير عمل CI يبني APK تلقائياً.

### قيود معروفة (معلنة بصدق)

- النموذج العصبي المحلي على الجهاز **قيد التكامل لاحقاً** — المحرك المحلي الحالي قاعدي.
- تحليل الصور سحابي فقط (Gemini) — لا تحليل محلي للصور.
- تشغيل الكود داخل المحرر مؤجل بدواعٍ أمنية.
